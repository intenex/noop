# TestFlight app icon

The TestFlight edition uses an original luminous mint and teal sensor ring with a pulse line,
on an opaque midnight-blue background. It contains no WHOOP mark or lettering. The primary
icon is shared by iPhone, Mac, and Apple Watch; the upstream alternate iPhone icon remains available.

Generated with the built-in image generation tool, then resized with Apple's image utility into
the native asset catalogs. No paid image API or hosted generation job was configured.
The 1024 × 1024 RGB master is [AppIcon-TestFlight.png](../DistributionResources/AppIcon-TestFlight.png).

Final generation prompt:

> Use case: logo-brand. Asset type: final square Apple iOS and macOS app icon artwork for NOOP, a private on-device fitness sensor companion. Create a remarkably polished, simple and distinctive native Apple app icon: a single sculpted luminous mint-teal open circular sensor ring centered on a deep midnight-blue background, with one elegant short heartbeat waveform inset through its centre. Restrained dimensional lighting, crisp precise edges, satin materials, strong silhouette legible at 32 pixels, premium calm fitness-tech character. The ring subtly suggests the letter N through the waveform without literal lettering. Centered composition with generous safe margins. Fill the entire 1024x1024 square with the opaque dark background; no external rounded-square mask, no border, no surrounding mockup. No words, letters, labels, watermark, third-party logos or WHOOP branding.
